# What If Donald Trump Had Grown Up in China?

**SCOPIVO · Episode 007 · 9:10 · Michael narration · 32 sections / 154 shot intervals**

[Watch online](https://tai23082004l02-svg.github.io/GPT-motion-canvas/?episode=china)

A fictional, satirical counterpart explores three possible paths: building, performance and political influence. Historical context is separated from invented scenes. No Trump voice clone, real quotation, predicted outcome or ethnic impersonation is used.

The edit changes composition about every four seconds, alternating a scene, an illustrated cutaway, a character reaction and a revised wide view. This is 154 shot intervals, including returns to earlier compositions, rather than 154 individually generated images. Round hands, stable head/body, Times New Roman/Liberation Serif and no scene-number counter are retained.
